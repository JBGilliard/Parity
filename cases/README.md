# Golden cases

Each directory is one isolated variable. `case.json` is the contract. Bars and signals are generated by `parity.cases` so the files stay tiny and deterministic.

```
uv run parity cases
uv run parity audit fill-timing-next-vs-same
uv run parity reproduce
```

Negative controls are the `*-matched` cases. `rebalance-ordering` is expected `unexplained` on purpose.
